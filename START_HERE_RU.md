# Studia — инструкция для друзей

В этом архиве находится исходный код сайта. Архив подготовлен без личной базы данных и без секретных ключей, поэтому после запуска каждый создаёт собственный аккаунт и начинает с пустого пространства.

## Быстрый запуск в Windows

1. Установите **Node.js 24 или новее** с сайта [nodejs.org](https://nodejs.org/).
2. Распакуйте ZIP в обычную папку. Не запускайте проект прямо из архива.
3. Откройте папку и дважды щёлкните `start-studia.cmd`.
4. При первом запуске дождитесь установки и сборки. Когда появится строка `Studia API`, откройте в браузере **http://localhost:5173/**.
5. Оставьте чёрное окно работающим, пока пользуетесь сайтом. Чтобы остановить сайт, нажмите `Ctrl+C` в этом окне.

Если запуск через файл не сработал, откройте PowerShell в папке проекта и выполните:

```powershell
npm ci
npm run dev
```

Затем откройте `http://localhost:5173/`. Для остановки нажмите `Ctrl+C` в терминале.

## Запуск в macOS или Linux

Установите Node.js 24+, откройте терминал в распакованной папке проекта и выполните:

```sh
npm ci
npm run dev
```

Откройте `http://localhost:5173/`. Остановить сервер можно сочетанием `Ctrl+C`.

## Что сделать после запуска

1. Создайте аккаунт через форму регистрации. Данные сохраняются в локальной SQLite-базе на компьютере.
2. Добавьте предметы или пары в расписание. Расписание связывает предметы с журналом оценок и другими учебными разделами.
3. Добавьте задачи и дедлайны, а затем при желании создайте конспект, карточки и материалы.
4. Журнал хранит баллы за работы; калькулятор показывает предварительный GPA с учётом указанных кредитов.
5. Для импорта расписания используйте CSV/TSV или вставку скопированной таблицы. Прямое подключение к Platonus в проекте не настроено.

## Gemini AI (необязательно)

Без API-ключа сайт и его основные разделы работают, но ИИ-помощник отвечать не будет. Чтобы включить его:

1. Получите **собственный** Gemini API key в Google AI Studio.
2. Скопируйте `.env.example` в файл `.env` в корне проекта.
3. Запишите ключ только в `.env`:

   ```env
   GEMINI_API_KEY=ваш_новый_ключ
   ```

4. Перезапустите сайт. Не вставляйте ключ в исходники, чат, скриншоты или архивы. Файл `.env` не включён в этот ZIP.

ИИ получает профиль и учебные записи текущего аккаунта для ответа. Предлагаемые им изменения нужно подтвердить в интерфейсе.

## Важно про аккаунты и группы

У каждого запуска на отдельном компьютере своя локальная база. Аккаунты, расписания и чаты **не синхронизируются между разными компьютерами автоматически**. Чтобы друзья общались в одной учебной группе, сайт нужно развернуть на общем сервере с HTTPS и общей постоянной базой данных; один только ZIP этого не делает.

## Если сайт не открылся

- Убедитесь, что установлена Node.js версии 24 или новее: `node -v`.
- Проверьте, что терминал открыт в папке, где лежит `package.json`.
- Если установка зависимостей завершилась ошибкой, проверьте интернет и повторите `npm ci`.
- Если порт 5173 уже занят, остановите другой запущенный экземпляр Studia и повторите запуск.
- Не пересылайте свой `.env`, базу `data/studia.db` или резервные копии: в них могут находиться секреты и личные данные.
