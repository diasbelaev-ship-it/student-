# Запуск Studia бесплатно в GitHub Codespaces

Codespaces запускает проект в облачном контейнере и выдаёт HTTPS-ссылку на сайт. Это удобно для показа друзьям с телефона или другого компьютера. Пока Codespace выключен, сайт по ссылке не открывается.

## Первый запуск

1. Откройте [репозиторий Studia](https://github.com/diasbelaev-ship-it/student-).
2. Нажмите **Code → Codespaces → Create codespace on main**. Выберите машину на **2 ядра** (если GitHub предлагает выбор), чтобы медленнее расходовать бесплатные core-hours.
3. Дождитесь завершения настройки. Конфигурация сама выполнит `npm ci`, `npm run build` и запустит сервер.
4. В нижней панели редактора откройте **Ports**. Для порта `3001` выберите **Port Visibility → Public**, затем скопируйте Forwarded Address. HTTPS-ссылка вида `https://ИМЯ-CODESPACE-3001.app.github.dev` откроет Studia. После смены видимости ссылку можно отправить друзьям.
5. Зарегистрируйте аккаунт в Studia. Облачная база начнётся пустой: данные из локального `data/` в GitHub не загружались.

Публичный порт доступен любому, кто знает URL. Учётные записи в приложении остаются отдельными; не размещайте в публичной версии секретные или чувствительные сведения.

## Включить снова и остановить

- Чтобы разбудить сайт, откройте [github.com/codespaces](https://github.com/codespaces) и нажмите **Start** у сохранённого Codespace. Сервер запускается автоматически; если нет — откройте Terminal и выполните `npm run codespace:start`.
- Чтобы остановить приложение в терминале, выполните `npm run codespace:stop`. Затем отдельно остановите сам Codespace через меню GitHub или страницу Codespaces. Закрытие вкладки браузера само по себе не останавливает облачную машину.
- Если сайт не отвечает, проверьте, что Codespace работает, порт `3001` виден в **Ports**, а сервер слушает этот порт. Запуск: `npm run codespace:start`; журнал: `/tmp/studia-codespace.log`.

## Бесплатный лимит и данные

По текущей таблице GitHub Free включает **120 core-hours и 15 GB-month хранилища Codespaces в месяц**. Для машины с 2 ядрами 120 core-hours соответствуют примерно **60 часам включённой работы** за расчётный месяц; учитывается также хранилище Codespace. Когда включённая квота исчерпана, GitHub может заблокировать запуск до её обновления; при платном использовании сверх лимита возможны начисления.

Чтобы ограничить риск платного превышения, в [Billing → Budgets and alerts](https://github.com/settings/billing) создайте бюджет продукта **Codespaces** на **$0** и включите **Stop usage when budget limit is reached** (если доступно для аккаунта). Это остановит дополнительное платное использование; при исчерпании бесплатной квоты Codespace может перестать запускаться до следующего месяца. Включите уведомления о 90% и 100% использованной квоты.

По умолчанию Codespace останавливается после **30 минут бездействия** и имеет максимум **12 часов** непрерывной работы. Остановленный Codespace сохраняет файлы проекта и `data/studia.db`, но его место продолжает учитываться в хранилище. Неактивный остановленный Codespace GitHub по умолчанию удалит через **30 дней**. Перед удалением сделайте резервную копию личных данных; не коммитьте базу и файлы групп в публичный репозиторий.

## Включение Gemini

Ключ, ранее показанный в чате или на скриншоте, нужно отозвать в Google AI Studio и выпустить новый. Никогда не сохраняйте ключ в репозитории.

1. На GitHub откройте **Settings → Secrets and variables → Codespaces → New repository secret**.
2. Имя секрета: `GEMINI_API_KEY`. Вставьте только новый ключ и сохраните.
3. Остановите и снова запустите Codespace, чтобы новый секрет появился в окружении. Сервер читает его только на backend.

Не добавляйте `.env`, базу `data/`, резервные копии, персональные файлы и настоящий API-ключ в публичный репозиторий.
