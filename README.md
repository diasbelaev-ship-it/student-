# Studia — учебное пространство студента

Адаптивный сайт на React, Express и SQLite. Работает локально в Google Chrome и других современных браузерах. Личные данные сохраняются в `data/studia.db` на вашем компьютере; общие записи видят только участники соответствующей учебной группы.

## Быстрый запуск в Windows

Откройте **Командную строку** и выполните команды именно в папке проекта:

```bat
cd /d "C:\путь\к\папке\Studia"
npm ci
npm run dev
```

После строки `Local: http://localhost:5173/` откройте **http://localhost:5173/** в Chrome. Пока пользуетесь сайтом, оставьте окно с `npm run dev` открытым. Для остановки нажмите `Ctrl+C`.

Можно также дважды щёлкнуть `start-studia.cmd` в папке проекта: скрипт сам перейдёт в правильную папку, установит зависимости при необходимости и запустит сайт одним сервером на порту 5173. Оставьте открывшееся окно работающим, пока пользуетесь сайтом. Если сайт уже запущен, скрипт просто откроет его в браузере.

Требуется **Node.js 24+**. Для установки зафиксированных версий используйте `npm ci`. Проверки: `npm run format:check`, `npm run build`, `npm run test:api`, `npm run test:ui` или все сразу через `npm run test:all`. После сборки можно запустить единый сервер командой `npm start` и открыть **http://localhost:3001/**. Для production настройте HTTPS, `NODE_ENV=production` и `CLIENT_ORIGIN` на реальный адрес сайта.

## Бесплатный запуск через GitHub Codespaces

В репозитории настроен GitHub Codespaces: откройте вкладку **Code → Codespaces → Create codespace on main**. Контейнер установит зависимости, соберёт интерфейс и запустит Studia на порту 3001. Чтобы поделиться сайтом, во вкладке **Ports** поменяйте видимость порта **3001** на **Public** и скопируйте его HTTPS-адрес. Адрес доступен, только пока Codespace и сервер работают. Инструкция с шагами, запуском и ограничениями — в [CODESPACES_RU.md](CODESPACES_RU.md).

Это бесплатный временный Codespace для показа/учёбы, а не постоянный 24/7 хостинг. Исходный код репозитория публичный; локальный `.env`, база `data/` и архивы не публикуются. Gemini включится после добавления **нового, отозванного/перевыпущенного ключа** в Codespaces Secret `GEMINI_API_KEY`; ключ из старого чата использовать не следует.

## Что работает

- Регистрация и вход, отдельные записи каждого пользователя, сохранение сессии.
- Главная «Сегодня» выделяет ближайший шаг: срочную личную задачу, следующую пару или общий дедлайн. Ниже — занятия, нагрузка по неделе, прогресс задач, журнал, предварительный GPA, конспекты и напоминания. Общий дедлайн открывает именно нужную группу. Даже новый аккаунт видит действия для заполнения разделов, а предмет не обязателен для создания пары или задачи.
- «Предметы» связывают занятия, задачи, оценки, конспекты, материалы и посещаемость. Старые записи сохраняются; подходящие по названию можно привязать вручную. При удалении предмета связанные записи остаются без привязки.
- Карточка предмета теперь показывает связанные записи из расписания, дедлайнов, журнала, ручного GPA, конспектов, библиотеки, карточек, напоминаний, посещаемости, учебного времени, целей, привычек и расходов. Новую запись можно создать прямо из предмета; в других разделах ссылка на предмет ведёт обратно к общей картине. Для старых записей без привязки учитывается только точное совпадение названия предмета в соответствующем поле, без рискованного угадывания по произвольному тексту. Предметы, уже встречающиеся в расписании, можно создать одной кнопкой.
- Из задачи с датой можно подготовить напоминание, а из любой задачи — конспект. В Pomodoro можно выбрать задачу и предмет; завершённая фокус-сессия попадёт в «Учебное время» и карточку предмета. Оценки журнала явно связываются с предметом, а расчёт GPA хранит новые веса кредитов по его ID, чтобы переименование не сбивало расчёт.
- Основное меню строится вокруг повседневных действий, предметов и совместной учёбы. Дополнительные личные инструменты доступны под «Другие инструменты». На телефоне снизу доступны «Сегодня», расписание, задачи и группы. Поиск по своим записям открывается кнопкой сверху или сочетанием `Ctrl+K`.
- «Учебные группы»: студент создаёт группу и передаёт одногруппникам код приглашения. Участники видят общий чат, дедлайны и файлы (PDF, PNG, JPG, WebP, TXT, DOCX, XLSX, PPTX до 5 МБ). Чат обновляется каждые 7 секунд, пока вкладка открыта. Общий дедлайн переносится в личный план только по кнопке «В мой план»; совпавший по названию личный предмет привязывается автоматически. Остальные личные записи группе не показываются. Каждый запрос к группе и скачивание файла проверяются по участию в ней. Файлы хранятся отдельно в `data/group-files/`.
- «Библиотека» показывает вместе личные материалы и файлы тех групп, в которых состоит студент. Можно искать по названию, предмету и группе, открыть личную ссылку, скачать общий файл или перейти в нужную группу. Права на файл повторно проверяются сервером при скачивании.

На `localhost` группы работают между аккаунтами на одном запущенном сервере. Чтобы одногруппники подключались со своих устройств через интернет, сайт понадобится развернуть на доступном сервере с HTTPS, постоянным хранилищем и резервными копиями.
- Расписание с ручным редактированием и разовым переносом скопированной таблицы или CSV/TSV. В окне «Перенести расписание» сначала показывается предпросмотр, затем сохраняются только новые занятия. Формат: `день,начало,конец,предмет,аудитория` либо `день,время,предмет` с диапазоном `09:00–10:30`; день — число от `0` (понедельник) до `6` (воскресенье) или название дня на русском/казахском. Допускаются `;`, запятые и табуляция, поля в кавычках.
- Отдельный «Журнал оценок» строит список предметов из расписания и раздела «Предметы» без дублирования. Студент вносит баллы за конкретные работы (получено / максимум); процент по предмету рассчитан только по внесённым работам. Если пару удалить, оценки остаются в журнале. Временные записи «Пара N — предмет не указан» не считаются дисциплинами; журнал показывает ссылки для их исправления в расписании.
- «Калькулятор GPA» автоматически берёт существующие оценки журнала и пересчитывается при их изменении. Можно указать кредиты каждого предмета (сохраняются в базе) и выбрать линейную или примерную ступенчатую шкалу перевода процентов в 4-балльную систему. Если кредиты не указаны, используется равный вес 1. Это **предварительная оценка**, не официальный GPA вуза: реальные веса работ и шкалы могут отличаться. Старые ручные GPA-записи сохранены в отдельном блоке и не смешиваются с автоматическим расчётом.
- Конспекты с поиском, Kanban-задачи, напоминания, Pomodoro, карточки, посещаемость, материалы, цели, привычки, учёт учебного времени и расходов. Карточки сгруппированы по тематическим наборам, ищутся по содержимому и могут хранить уровень, произношение, пример с переводом и подсказку по употреблению. Старые карточки с одним вопросом и ответом остаются доступными.
- Дата сессии в профиле и обратный отсчёт на главной странице.
- Gemini: сервер получает вопрос, имя/дату сессии, количество личных записей по разделам, до 120 последних личных записей и пример из каждого оставшегося раздела (длинные конспекты сокращаются), а также ID и названия групп пользователя. Помощник может предложить создание, изменение или удаление личной записи, настройку GPA, изменение профиля и длительности Pomodoro. Для запроса вроде «добавь пять пар» он может подготовить до 30 новых записей одним пакетом; для изменения нескольких существующих записей — пакет до 30 правок. Если для пары не указан предмет, ИИ должен попросить уточнение вместо создания фиктивного предмета. Он также составляет тематические наборы карточек с примерами и подсказками и может дополнить существующие карточки. По просьбе пользователя ИИ может предложить общий дедлайн или сообщение в группе, где пользователь состоит. Перед отправкой группе показываются адресат и содержание; запись появляется у участников только после явного подтверждения. Членство проверяется при предложении и повторно при подтверждении. Совпадающие новые занятия и карточки пропускаются. Личные изменения также показываются перед сохранением и доступны для подтверждения владельцу в течение 10 минут; устаревшая правка не перезаписывает более новую. Таймер не запускается автоматически. Переписку и файлы группы ИИ не получает; доступа к Platonus, браузерным разрешениям и данным других пользователей у него нет.

В разделе «Напоминания» разрешите системные уведомления и нажмите «Проверить»: появится пробное сообщение внутри сайта и, если браузер разрешил, системное уведомление со звуком. Звук включён по умолчанию, если вы не выключили его вручную. Браузер может требовать первое нажатие пользователя, чтобы разблокировать звук. Напоминание с выбранным интервалом (например, за 5, 15 или 30 минут) показывается один раз. Если открытая вкладка была усыплена, проверка повторится при возвращении; пропущенное предупреждение показывается до начала события и ещё 5 минут после него. Системные уведомления зависят от разрешения браузера и настроек уведомлений/звука Windows. При полностью закрытом браузере локальный сайт не может доставить уведомление: для этого нужен отдельный сервис фоновых push-уведомлений.

## Ключ Gemini

Если вы хотите включить помощника, скопируйте `.env.example` в `.env` и задайте `GEMINI_API_KEY` только там. `.env` исключён из Git. Ключ, показанный в переписке/скриншоте, уже раскрыт: рекомендуется отозвать его в Google AI Studio и выпустить новый. Сервер использует модель из `GEMINI_MODEL` (по умолчанию `gemini-3.5-flash-lite`).

После установки нового ключа перезапустите `npm run dev`. Проверить Gemini можно командой `node --test tests/gemini-smoke.test.js tests/gemini-actions.test.js`: тесты получают ответ и проверяют предложение действия в отдельной временной базе; ключ в вывод не попадает.

Для ALT Platonus используйте адрес `https://platonus.alt.edu.kz/`: войдите в личный кабинет **на самом Platonus**, откройте «Расписание», скопируйте табличные данные и вставьте их в окно переноса Studia. Если формат скопированной страницы не распознаётся, экспортируйте/подготовьте CSV/TSV по шаблону выше. Данные для входа, код подтверждения и сессия Platonus в Studia не передаются. Автоматическая синхронизация и официальный API не заявлены: их доступность нужно подтвердить у университета/поставщика. Для точного адаптера под внутренний формат Platonus понадобится обезличенный образец таблицы из личного кабинета.

## Структура

- `src/` — React-интерфейс, hooks, общие компоненты и стили разделов.
- `server/index.js`, `server/app.js`, `server/auth.js`, `server/items.js` — API, сессии, проверка данных и права доступа.
- `server/db.js`, `server/migrations/` — SQLite и последовательные миграции, автоматически резервирующие БД перед изменением схемы.
- `server/groups.js` — API учебных групп, чат, файлы, общие дедлайны и проверки членства.
- `scripts/` — оптимизация изображений, резервное копирование, восстановление и упаковка проекта.
- `tests/` — API, безопасность, сохранность миграций, CSV/GPA и React UI.
- `data/studia.db` — локальная база SQLite, создаётся автоматически и не включается в Git.
- `data/group-files/` — файлы групп, не включаются в Git; при резервном копировании сохраняйте вместе с базой.

## Настройки и данные

Скопируйте `.env.example` в `.env`. `GEMINI_API_KEY` задаётся только на сервере; ранее показанный в переписке ключ отзовите и замените. Включение подтверждения email (`REQUIRE_EMAIL_VERIFICATION=true`) требует SMTP: укажите `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` и `MAIL_FROM`. Для локальной разработки без SMTP подтверждение выключено. При публикации в production обязательны HTTPS, корректный `CLIENT_ORIGIN` и SMTP, если включена проверка почты.

Миграции выполняются в SQLite через `PRAGMA user_version`. Перед изменением схемы автоматически создаётся резервная копия. Для ручной копии выполните `npm run backup`; в ней содержатся БД и файлы групп. Перед восстановлением остановите сервер Studia. Выполните `npm run restore -- "путь\к\папке-копии" --yes`, затем снова запустите сервер. Перед заменой создаётся страховая копия текущих данных. Хранение ежедневных автоматических копий включается только переменной `BACKUP_ENABLED=true`; число хранимых копий задаёт `BACKUP_KEEP`.

Для передачи исходников запустите `npm run handoff:zip`. ZIP не содержит базу, историю чата, `.env`, архивы, `node_modules` или `dist`. Включайте личную базу только по явному запросу через `python scripts/package_handoff.py --include-data`; в ней находятся аккаунты и учебные записи. История чата добавляется только параметром `--include-history`.

Шрифты Manrope и DM Sans и производные AVIF/WebP/JPEG-иллюстрации хранятся локально. Исходное изображение находится в `assets-src/`; пересобрать оптимизированные форматы можно командой `npm run images`.

Для развертывания в интернете перед публикацией настройте домен, TLS, постоянное хранилище и проверяемые резервные копии. `npm run dev` предназначен для локальной работы.
